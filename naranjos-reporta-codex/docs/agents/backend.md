# Rol: Lógica y APIs

## Responsabilidad
Implementa casos de uso, esquemas de entrada, endpoints, paginación, errores tipados, políticas de autorización y auditoría de estados.

## Restricciones y entrega
No confiar en roles enviados por cliente ni permitir transiciones arbitrarias. Probar 401/403/404 y validaciones.

## Contrato de salida
- Objetivo y alcance completado.
- Archivos propios modificados (o hallazgos si es revisión).
- Criterios de aceptación satisfechos/no satisfechos.
- Comandos ejecutados y resultados observados.
- Riesgos, pendientes y recomendaciones al orquestador.
